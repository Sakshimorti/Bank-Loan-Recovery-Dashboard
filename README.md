# 💰 Bank Loan Recovery Dashboard

## 📌 Project Name
**Bank Loan Recovery Dashboard**

---

## 📖 Short Description / Purpose

The **Bank Loan Recovery Dashboard** is an interactive Power BI dashboard designed to analyze and monitor bank loan recovery performance.  
This dashboard helps banks and financial institutions track:

- Total Due Amount
- Total Recovered Amount
- Remaining Due Amount
- Recovery Methods Performance
- Bank-wise Recovery Analysis
- Loan Type Analysis
- Customer Recovery Details
- Recovery Trends by Month and Year

The main purpose of this dashboard is to provide clear business insights for improving loan recovery efficiency and reducing pending dues.

---

## 🛠️ Tech Stack

The following tools and technologies were used to build this project:

- **Power BI** → Dashboard creation and data visualization
- **Microsoft Excel / CSV** → Dataset storage
- **DAX (Data Analysis Expressions)** → Calculated measures and KPIs
- **Power Query** → Data cleaning and transformation
- **ChatGPT (AI Tool)** → Dataset generation and project assistance

## ✨ Features / Highlights

### 📌 Business Problem

Banks and financial institutions often face challenges in tracking loan recovery performance across multiple banks, customers, and recovery methods.  
Manual analysis makes it difficult to identify recovery trends, pending dues, and high-performing recovery channels.

---

### 🎯 Goal of the Dashboard

The dashboard aims to:

- Monitor total due and recovered loan amounts
- Analyze recovery performance bank-wise
- Compare AI-based, Agent-based, and Field-Agent recoveries
- Identify pending loan amounts
- Track monthly and yearly recovery trends
- Improve decision-making using visual analytics

---
